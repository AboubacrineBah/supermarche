Franc CFA (XOF) · Mali · UEMOA

Version 1.0 — Novembre 2026

1. Résumé exécutif (Brief)

SuguPro est une application web de gestion complète pour les supermarchés et supérettes de l'Afrique de l'Ouest, conçue pour le Franc CFA (XOF) et le contexte local (Mobile Money, ventes à crédit, gestion multi-caisses, alertes WhatsApp/SMS).

  • Cible : supérettes et supermarchés (Bamako, Dakar, Abidjan).
  • Problèmes résolus : démarque inconnue, gestion multi-caisses, ventes à crédit, péremption, rupture de stock.
  • Modèle économique : SaaS mensuel/annuel en FCFA (Starter 25 000 FCFA/mois, Pro 50 000 FCFA/mois) + installation/matériel.
  • Stack : Laravel 13, PHP 8.3, MySQL, Bootstrap 5, Vite.

4. Modules fonctionnels (détail)

4.1 POS / Caisse

  • Interface tactile de vente, scan code-barres, panier.
  • Paiements multi-modes : espèces, Orange Money, Wave, Moov Money, carte, crédit.
  • Calcul automatique de la monnaie, impression ticket thermique.
  • Ouverture/fermeture de caisse (Z de caisse), écart de caisse.
  • Décrémentation automatique du stock à la vente.

4.2 Gestion des stocks & produits

  • Catalogue produits (SKU, code-barres EAN-13, catégories, unités).
  • Prix d'achat, détail, gros (avec quantité minimale).
  • Alertes stock minimum, produits en rupture.
  • Mouvements de stock (ouverture, achat, vente, ajustement, perte, retour).
  • Verrouillage pessimiste pour éviter les ventes simultanées.

4.3 Fournisseurs & achats

  • Fiches fournisseurs (NIF, conditions de paiement, plafond de dette).
  • Bons de commande (brouillon, envoyé, reçu partiel/total).
  • Réception marchandise avec mise à jour automatique du stock.
  • Historique des réceptions et dettes fournisseurs.

4.4 Clients & crédit

  • Fiches clients (téléphone, WhatsApp, email, adresse).
  • Plafond de crédit et solde créditeur.
  • Ventes à crédit (ardoise numérique).
  • Relances automatiques (WhatsApp/SMS).

4.5 Notifications

  • WhatsApp Cloud API (Meta) : envoi de reçus numériques, alertes stock.
  • SMS (Orange, AfricasTalking, Twilio) : rappels d'échéance, alertes rupture.
  • Architecture découplée via MessagingChannelInterface.

4.6 Multi-tenant & sécurité

  • Isolation stricte par magasin (global scope Eloquent).
  • CSRF, validation via FormRequest, échappement Blade, Eloquent (pas de SQL brut).
  • Rate-limiting sur l'authentification.
  • Audit des dépendances (composer audit, npm audit).

5. Sécurité & qualité

  • Laravel Pint (PSR-12), Larastan/PHPStan, PHPUnit.
  • Tests feature : authentification, isolation tenant, CRUD produits, stocks, POS.
  • CI GitHub Actions : pint, phpstan, phpunit, build Vite.
  • PWA : manifest + Service Worker (installable Android/iOS).

6. Déploiement

  • XAMPP (Apache/MySQL) pour l'installation locale.
  • Laravel Cloud pour la production.
  • Guide d'installation complet dans docs/04-GUIDE-INSTALLATION.md.
