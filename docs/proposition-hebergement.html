1. Analyse de l'application

L'application SuguPro est un ERP/POS web multi-tenant pour la gestion de supermarchés, conçu pour le contexte ouest-africain (Franc CFA, Mobile Money, ventes à crédit).

4. Sécurité (priorité haute)

4.1 Sécurité réseau

  • Pare-feu (UFW) : seul les ports 22 (SSH), 80 (HTTP), 443 (HTTPS) ouverts. MySQL (3306) inaccessible depuis l'extérieur.
  • SSH sécurisé : authentification par clé uniquement, désactivation de l'authentification par mot de passe, port SSH personnalisé, Fail2Ban pour bloquer les tentatives de brute-force.
  • HTTPS obligatoire : certificat SSL Let's Encrypt (renouvellement automatique), redirection HTTP → HTTPS.
  • Protection DDoS : Hetzner inclut une protection DDoS de base. Cloudflare (gratuit) en frontal pour WAF et cache.

4.2 Sécurité applicative

  • CSRF : protection sur tous les formulaires (Laravel).
  • Validation : FormRequest stricts, échappement Blade (XSS), Eloquent (injection SQL).
  • Authentification : rate-limiting sur le login (5 tentatives/min), sessions chiffrées.
  • Autorisation : Spatie Permission (rôles et permissions), Gate::before pour super-admin.
  • Multi-tenant : isolation stricte par magasin via Global Scope Eloquent.
  • Secrets : variables d'environnement (.env), jamais commitées dans Git.

4.3 Sécurité des données

  • Sauvegardes automatiques : dump MySQL quotidien (cron) + stockage sur Hetzner Cloud Storage (S3 compatible) ou volume séparé.
  • Rétention : 30 jours de sauvegardes quotidiennes, 12 mois de sauvegardes mensuelles.
  • Chiffrement : volumes Hetzner chiffrés au repos (option), TLS en transit.
  • Tests de restauration : vérification mensuelle de la restauration des sauvegardes.

4.4 Monitoring & alertes

  • Uptime monitoring : Uptime Kuma (self-hosted) ou UptimeRobot (gratuit) — alerte si le site est down.
  • Logs : Laravel logs + rotation quotidienne, accès via SSH.
  • Mises à jour : mises à jour de sécurité automatiques (unattended-upgrades) pour le système.

7. Plan de mise en production

  1. Semaine 1 : Provisionner le VPS Hetzner, installer Ubuntu 24.04 LTS, Nginx, PHP 8.3, MySQL 8, Redis.
  2. Semaine 1 : Configurer le pare-feu, SSH par clé, Fail2Ban, SSL Let's Encrypt.
  3. Semaine 2 : Déployer l'application (Git clone, composer install, npm run build, migrations, seeders).
  4. Semaine 2 : Configurer les sauvegardes automatiques et le monitoring.
  5. Semaine 3 : Tests d'acceptation en conditions réelles (POS, stocks, caisse).
  6. Semaine 3 : Formation des utilisateurs (caissiers, gérant, magasinier).
  7. Semaine 4 : Mise en production et bascule.

8. Conclusion

La solution VPS Hetzner offre le meilleur rapport qualité/prix pour héberger SuguPro en Afrique de l'Ouest. Avec le Pack Pro (4 vCPU, 8 Go RAM, 80 Go NVMe, ~6 600 FCFA/mois), l'application dispose de ressources confortables pour un supermarché de taille moyenne avec plusieurs caisses, tout en garantissant la sécurité des données et la disponibilité du service.

L'architecture (Nginx + PHP-FPM + MySQL + Redis) est éprouvée, et les sauvegardes automatiques quotidiennes protègent contre la perte de données. La latence vers l'Afrique de l'Ouest (~80-120ms) est acceptable pour une application web transactionnelle.
